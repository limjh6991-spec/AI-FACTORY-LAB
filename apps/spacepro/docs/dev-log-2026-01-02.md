## Phase 3: 이월 생산 (진행률 관리)

### DB 변경
```sql
CREATE TABLE spacepro.tb_order_progress (
    progress_id SERIAL PRIMARY KEY,
    scenario_id INT REFERENCES tb_simulation_scenario,
    item_code VARCHAR(50),
    planned_qty INT,
    produced_qty INT DEFAULT 0,
    status VARCHAR(20) DEFAULT 'PLANNED',
    priority VARCHAR(20),
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

ALTER TABLE tb_simulation_scenario ADD COLUMN status VARCHAR(20) DEFAULT 'DRAFT';
```

### 새 API 엔드포인트
| Endpoint | Method | 설명 |
|----------|--------|------|
| `/scenarios/{id}/confirm` | POST | 시나리오 확정 |
| `/scenarios/{id}/progress` | GET | 진행 현황 조회 |
| `/progress/{id}` | PUT | 진행률 업데이트 |
| `/carry-over/{plan_month}` | GET | 이월 대상 조회 |

### UI 버튼 추가
- **[확정]**: 시나리오 확정, 진행 추적 시작
- **[이월 가져오기]**: 전월 미완료 오더 가져오기
