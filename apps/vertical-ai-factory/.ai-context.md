## 🏗️ Clean Architecture 구조

```
src/
├── config.py                    # LLM 설정 (gemini-2.5-flash) + .env 자동 로드
├── main.py                      # CLI 엔트리포인트 (Rich UI)
├── api_server.py                # FastAPI 서버

├── domain/                      # Domain Layer (핵심 비즈니스 로직)
│   ├── state.py                 # AgentState (company_code, graph_context 포함)
│   └── agents/
│       ├── analyst.py           # 의도 분석 → Plan 생성 (graph_context 지원)
│       ├── writer.py            # Plan → SQL 생성
│       └── critic.py            # SQL 검증 및 피드백

├── application/                 # Application Layer (Use Cases)
│   └── graph.py                 # LangGraph 워크플로우
│                                # (graph_context → Analyst → Writer → Critic)

├── infrastructure/              # Infrastructure Layer (외부 시스템 연동)
│   ├── knowledge_graph.py       # 🆕 NetworkX 기반 Knowledge Graph
│   ├── database/
│   │   ├── mock_db.py           # SQLite Mock DB (costs 테이블)
│   │   └── init_knowledge_graph.py  # 🆕 PostgreSQL bi_common_code 연동
│   └── tools/
│       └── graph_search_tool.py # 🆕 LangChain Tool 래핑

└── interfaces/                  # Interface Layer (API 어댑터)
    └── ...                      # FastAPI 라우터 등
```

│  ┌─────────────┐   ┌─────────┐   ┌────────┐   ┌────────┐   │

│  └─────────────┘   └─────────┘   └────────┘   └────────┘   │

## 🔧 개발 시 참고사항

### 1. 환경 변수 (.env)
```bash
GOOGLE_API_KEY=your-google-api-key
POSTGRES_URL=postgresql://postgres:postgres@localhost:5432/ai_factory_db
```

### 2. LLM 모델 설정 (src/config.py)
```python
# 현재: Gemini 사용, .env 자동 로드
MODEL_CONFIG = {
    "analyst": "gemini-2.5-flash",
    "writer": "gemini-2.5-flash", 
    "critic": "gemini-2.5-flash",
}
```

### 3. 실행 방법
```bash
cd /home/roarm_m3/ai-factory-lab/apps/vertical-ai-factory

# CLI 실행
./venv/bin/python src/main.py

# API 서버 실행
./venv/bin/python src/api_server.py

# Knowledge Graph 초기화
./venv/bin/python src/infrastructure/database/init_knowledge_graph.py
```

### 4. Knowledge Graph 사용
```python
from infrastructure.knowledge_graph import get_knowledge_graph
from infrastructure.database.init_knowledge_graph import init_knowledge_graph

# 초기화 (첫 실행 시)
kg = init_knowledge_graph(use_cache=False)

# 이후 사용 (캐시 로드)
kg = get_knowledge_graph()
context = kg.search_by_question("부서 목록", "BINARY")
```
