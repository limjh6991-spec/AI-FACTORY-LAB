### 2. 작업 캘린더 테이블 신규 생성

```sql
CREATE TABLE spacepro.sp_work_calendar (
    id SERIAL PRIMARY KEY,
    calendar_date DATE NOT NULL,
    shift_id VARCHAR(20),       -- DAY/NIGHT/SWING
    working_hours NUMERIC(4,2),
    is_holiday BOOLEAN,
    holiday_name VARCHAR(100),
    site_id VARCHAR(20)
);
```

- **데이터**: 1,095건 (2026년 365일 x 3교대)
- **공휴일**: 42일 (한국 공휴일 반영)
