## 세부공정 라우팅 화면 개선

### 1. 필터 시스템 개선
- **사업팀 필터 추가**: 필터 맨 앞에 사업팀(연소관팀, 노즐팀, 항공팀) 드롭다운 추가
- **필터 Hierarchy 구현**: 사업팀 → 계약 → 제품 → 공정 순서로 캐스케이드 필터
- **API 업데이트**: 
  - `/pr-detail/teams` - 사업팀 목록 조회
  - `/pr-detail/contracts?team_id=` - 팀별 계약 필터
  - `/pr-detail/products?contno=` - 계약별 제품 (wbs_vid 포함)

### 2. 제품 트리 구조 표시
- **wbs_vid 기반 정렬**: sp_macode_info 테이블의 wbs_vid 컬럼 값으로 정렬
- **필터 드롭다운**: wbs_vid depth에 따른 들여쓰기 (└ 표시)
- **라우팅 테이블**: 들여쓰기 + wbs_vid 값 표시
- **예시**:
  ```
  IAHANWCQ (1.1)
  IAHANWDJ-01 (1.2)
    └ IAHANWCY-01 (1.2.1)
    └ IAHANWDF-01 (1.2.2)
  ```

### 3. 공정 순서 정렬 수정
- **pr_seq 기준 정렬**: 데이터 조회 시 pr_seq → pr_detail_seq 순서로 정렬
- **백엔드 저장 시 pr_seq 반영**: UPDATE 쿼리에 pr_seq, pr_detail_seq 포함
- **프론트엔드 저장 시 pr_seq 전달**: 불러오기 및 추가 시 pr_seq 값 포함

### 4. 배치 저장 기능 구현
- **즉시 저장 → 대기 저장 방식으로 변경**
- **추가 대기**: 모달에서 추가 시 pendingAdditions에 저장
- **삭제 대기**: 휴지통 클릭 시 실제 삭제 없이 pendingDeletions에 마킹
- **저장되지 않은 변경사항 표시**: 제목 옆 주황색 펄스 배지
- **저장/취소 버튼**: 변경사항 있을 때만 헤더에 표시
- **삭제 예정 스타일**: 빨간 배경 + 투명도 + 취소선 + "삭제 예정" 배지
