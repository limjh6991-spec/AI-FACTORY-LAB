# SpacePro Development Log - 2025-12-30

## 라우팅 기반 생산 부하 시뮬레이션 시스템 구현

### 📌 작업 개요
- **목표**: 품목별 공정 흐름(Routing)을 기반으로 생산시간 계산 및 수율 분석 시스템 구축
- **기술 스택**: PostgreSQL, Python (FastAPI), Next.js 15

---

## ✅ 구현 완료 항목

### 1. Database Schema
| 테이블 | 설명 |
|--------|------|
| `tb_routing_mst` | 품목별 공정 라우팅 마스터 (리비전 관리) |
| `tb_bom_process` | 공정별 자재 투입 BOM |
| `tb_machine_event` | 설비 MTBF/MTTR 신뢰성 정보 |

**DDL 파일**: `scripts/sql/create_routing_tables.sql`

### 2. Python Simulation Engine
**파일**: `scheduling-service/solvers/routing_simulator.py`

| 클래스 | 기능 |
|--------|------|
| `YieldCompensator` | 수율 역산 (투입량 계산) |
| `FailureGenerator` | MTBF/MTTR 기반 랜덤 고장 생성 |
| `RoutingSimulator` | 이산 이벤트 시뮬레이션 실행 |
| `RoutingSimulationService` | DB 연동 서비스 레이어 |

### 3. FastAPI Endpoints
| Endpoint | Method | 설명 |
|----------|--------|------|
| `/routing/items` | GET | 라우팅 등록 품목 조회 |
| `/routing/{item_code}` | GET | 품목별 라우팅 + BOM 조회 |
| `/routing/yield-analysis` | POST | 수율 분석 (투입량/자재 역산) |
| `/routing/simulate` | POST | 시뮬레이션 실행 |
| `/routing/machines/reliability` | GET | 설비 신뢰성 조회 |

### 4. Frontend (Next.js)
**화면**: `/plan/routing` - 공정 흐름 분석

**주요 기능**:
- 제품 선택 (METAL-001, CHEM-002)
- 공정 흐름도 시각화 (화살표 다이어그램)
- 공정별 소요시간 계산
- 자재 소요량 표시 (수율 반영)
