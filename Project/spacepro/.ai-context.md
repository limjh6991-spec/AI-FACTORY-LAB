## 📊 데이터베이스

**PostgreSQL 연결:**
```
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/binary?schema=spacepro"
```

**주요 테이블 (Prisma Schema):**
- `tb_menu_mst` - 메뉴 마스터 (계층 구조)
- `tb_item_mst` - 품목 마스터 (RAW/SEMI/PRODUCT)
- `tb_bom_mst` - BOM (자재명세서)
- `tb_process_mst` - 공정 마스터
- `tb_machine_mst` - 설비 마스터
- `tb_worker_mst` - 작업자 마스터

**Prisma 명령어:**
```bash
npx prisma generate    # 클라이언트 생성
npx prisma db push     # 스키마 동기화
npx ts-node --esm prisma/seed.ts  # 시드 실행
```

## 🔧 개발 시 참고사항

### 1. Prisma 7 특이사항
```typescript
// src/lib/prisma.ts - pg 어댑터 사용 필수
import { Pool } from 'pg';
import { PrismaPg } from '@prisma/adapter-pg';
import { PrismaClient } from '@/generated/prisma';

const pool = new Pool({ connectionString: process.env.DATABASE_URL });
const adapter = new PrismaPg(pool, { schema: 'spacepro' });
const prisma = new PrismaClient({ adapter });
```

### 2. AG Grid v35+
```typescript
// 모듈 등록 필수
import { ModuleRegistry, AllCommunityModule } from 'ag-grid-community';
ModuleRegistry.registerModules([AllCommunityModule]);

// pinned 타입 지정
pinned: 'left' as const,
```

### 3. 메뉴 API
- `GET /api/menus` → 계층 구조 JSON 반환
- `DynamicSidebar.tsx`에서 사용

### 4. 생산 계획 공식
```
생산 계획량 = MAX(0, 판매 계획 - 전월 재고 + 안전 재고)
```
