프롬프트 1 (로드맵 생성)
지금부터 'Vertical AI Factory'라는 다중 에이전트 시스템을 구축할 거야.
LangGraph와 Python을 기반으로 Analyst, Writer, Critic 3단계 에이전트를 구현할 거야.

우선, 현재 디렉토리에 `PROJECT_ROADMAP.md` 파일을 생성하고 아래 내용을 그대로 작성해줘.
이 파일은 네가 앞으로 작업을 진행하면서 진행 상황을 체크하는 기준이 될 거야.

## 🚀 Vertical AI Factory Development Plan

### Phase 1: 기반 환경 구축 (Foundation)
- [ ] 프로젝트 구조 생성 (folders: agents, core, tools, config)
- [ ] 가상환경 및 `requirements.txt` 설치 (langgraph, langchain-openai, pydantic, sqlite3)
- [ ] 환경 변수 관리 (`.env`) 설정

### Phase 2: 도구(Tools) 및 MCP 모의 구현
- [ ] Mock DB 생성 (테스트용 SQLite, `costs` 테이블 등)
- [ ] Tool: `SchemaInspector` (DB 구조 조회용)
- [ ] Tool: `QueryValidator` (SQL 문법 검증용)

### Phase 3: 에이전트 개별 구현 (Agents)
- [ ] **Analyst Agent**: 사용자 의도 파악 및 기획 (Prompt + Logic)
- [ ] **SQL Writer Agent**: SQL 생성 (Prompt + Logic)
- [ ] **Critic Agent**: 쿼리 안전성/효율성 검증 (Prompt + Logic)

### Phase 4: 오케스트레이션 (Graph)
- [ ] LangGraph State 정의 (Agent 간 메시지 전달 구조)
- [ ] Workflow 연결 (Analyst -> Writer -> Critic -> End/Retry)
- [ ] Main Entrypoint (`main.py`) 작성

### Phase 5: 테스트 및 검증
- [ ] 시나리오 테스트: "10월 원가 분석해줘" -> SQL 생성 결과 확인

 Step 2: Analyst (기획자) & Writer (기술자) 구현
이제 뇌(Analyst)와 손(Writer)을 만듭니다.

💻 프롬프트 3
'Phase 3'의 Analyst와 SQL Writer 에이전트를 구현하자. 
`src/agents/` 폴더에 각각 파일을 생성해줘.

1. **Analyst Agent (`analyst.py`)**:
   - 역할: 사용자의 질문을 받아서 비즈니스 로직을 해석.
   - 도구: 앞서 만든 `get_schema_info`만 사용 가능 (데이터 조회 금지).
   - 출력: 어떤 테이블을 써서 어떤 조건으로 조회해야 하는지 자연어로 된 'Plan'을 반환.
   - Pydantic을 사용해서 구조화된 출력(thought, plan)을 하게 해줘.

2. **SQL Writer Agent (`writer.py`)**:
   - 역할: Analyst의 Plan을 보고 실행 가능한 SQL을 작성.
   - 규칙: 오직 `SELECT` 문만 작성 가능. (`DELETE`, `DROP` 절대 금지 시스템 프롬프트 주입).
   - 출력: SQL 쿼리 문자열.\

Step 3: Critic (보안관) 구현
가장 중요한 검증 단계를 구현합니다.
'Phase 3'의 마지막, Critic 에이전트를 `src/agents/critic.py`에 구현하자.

1. **Critic Agent**:
   - 입력: Writer가 작성한 SQL.
   - 역할: 
     a) 보안 검사 ('DROP', 'DELETE', 'UPDATE' 키워드 포함 시 Fail).
     b) 효율성 검사 (LIMIT가 없으면 경고).
   - 출력: Pydantic으로 `validation_result` (bool), `feedback` (str)을 반환.
   - 만약 `validation_result`가 False면 Writer에게 피드백을 주며 다시 시키는 로직을 염두에 둬야 해.

Step 4: LangGraph로 연결 (오케스트레이션)
이제 따로 노는 아이들을 하나의 팀으로 묶습니다.

💻 프롬프트 5
'Phase 4'를 진행하자. `src/graph.py`를 생성해서 LangGraph로 워크플로우를 짜줘.

1. `AgentState` 클래스 정의 (messages, plan, sql_query, critique_count 등).
2. 노드 연결:
   - Start -> Analyst -> Writer -> Critic
   - Critic(검증) 통과 시 -> End
   - Critic(검증) 실패 시 -> Writer (재작성 요청, feedback 전달)
   - 재작성 루프는 최대 3회로 제한해줘 (무한루프 방지).
3. 이 그래프를 실행할 수 있는 `main.py`를 작성해서, "10월달 식비가 얼마나 나왔어?"라고 물어보는 테스트 코드를 포함해줘.
