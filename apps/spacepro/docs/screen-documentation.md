## 1. 공정 라우팅 (기준정보 > 공정라우팅)

### 화면 개요
| 항목 | 내용 |
|------|------|
| 경로 | `/master/routing-carbon` |
| 목적 | 제품별 생산 공정 순서 및 표준시간 관리 |
| 디자인 | IBM Carbon Design System 적용 |

### 핵심 기능
1. **제품-공정 맵핑**
   - 제품코드별 공정 순서(OP_SEQ) 정의
   - 공정별 담당 설비(Machine) 지정

2. **표준 시간 관리**
   - Setup Time: 공정 준비 시간
   - Cycle Time: 단위당 가공 시간
   - Process Yield: 공정 수율 (%)

3. **CRUD 기능**
   - 라우팅 조회/추가/수정/삭제
   - 품목 검색 및 필터링

### 데이터 구조
```
tb_routing_mst
├── item_code (품목코드)
├── op_seq (공정순서)
├── op_name (공정명)
├── machine_code (설비코드)
├── setup_time (준비시간, 분)
├── cycle_time (가공시간, 분/EA)
└── process_yield (수율, %)
```

### 활용 시나리오
- 신제품 등록 시 공정 흐름 정의
- 공정 개선 후 표준시간 업데이트
- 설비 변경 시 라우팅 재배치

## 2. Capacity 시뮬레이션 (생산계획 > 생산 케파 시뮬레이션)

### 화면 개요
| 항목 | 내용 |
|------|------|
| 경로 | `/plan/capacity` |
| 목적 | 설비별 생산능력 대비 부하 분석 |
| 알고리즘 | 수율/재가공/비가동 반영 시뮬레이션 |

### 핵심 기능
1. **워크센터별 수요 입력**
   - 제품별 계획 수량 입력
   - 일간/주간 생산 목표 설정

2. **고급 파라미터 설정**
   - Yield Rate: 양품률 (기본 98%)
   - Rework Rate: 재가공률 (기본 2%)
   - Downtime: 비가동 시간

3. **시뮬레이션 결과 분석**
   - 설비별 가동률 (%)
   - 병목 공정 자동 감지
   - Over Capacity 경고

### 계산 로직
```
실제 필요 시간 = (계획수량 × 표준시간) ÷ 수율
비가동 반영 = 실제 필요 시간 + Downtime
가동률 = (비가동 반영 시간 ÷ 가용 시간) × 100%
```

### 시각화 요소
- Workcenter별 막대 차트 (가동률)
- 상태별 파이 차트 (적정/과부하/유휴)
- 병목 알림 카드

### 버전 관리
- 시뮬레이션 결과 저장/불러오기
- 시나리오별 비교 분석 가능

## 4. 생산 시뮬레이션 (생산계획 > 생산 시뮬레이션)

### 화면 개요
| 항목 | 내용 |
|------|------|
| 경로 | `/plan/simulation` |
| 목적 | 다중 제품 동시 생산 스케줄 최적화 |
| 스케줄러 | Google OR-Tools CP-SAT Solver |

### 핵심 기능

#### A. 주문 관리
- 제품별 생산 수량 입력
- **우선순위 설정**: 일반/높음/긴급
- 라우팅 자동 로드

#### B. 스케줄링 알고리즘
| 알고리즘 | 설명 |
|----------|------|
| FIFO | 입력 순서대로 배치 |
| SPT | 최단 가공시간 우선 |
| LPT | 최장 가공시간 우선 |
| **OR_TOOLS** | 제약조건 만족 최적화 |

#### C. 간트 차트 시각화
- 설비별 타임라인 표시
- 제품별 색상 구분
- 작업 충돌 감지 및 표시

#### D. 설비 가동률 분석
- 설비별 활용률 (%)
- 유휴 시간 분석

### OR-Tools 스케줄링 로직
```python
# 제약조건
1. 한 설비에 동시 작업 불가 (NoOverlap)
2. 공정 순서 준수 (선행공정 완료 후 후행공정)
3. 우선순위 반영 (URGENT → HIGH → NORMAL)

# 목적함수
minimize(makespan)  # 총 생산시간 최소화
```

### 시나리오 관리
- **계획월(plan_month)** 기반 시나리오 분리
- 저장: 신규/업데이트 선택 가능
- 불러오기: 드롭다운 선택

### 이월 관리
- **[확정]** 버튼: 시나리오 확정 → 진행 추적 시작
- **[이월 가져오기]** 버튼: 전월 미완료 오더 자동 추가

### 데이터 구조
```
tb_simulation_scenario
├── scenario_id (PK)
├── scenario_name
├── plan_month (YYYY-MM)
├── algorithm (FIFO/SPT/LPT/OR_TOOLS)
├── orders (JSONB)
├── result (JSONB)
└── status (DRAFT/CONFIRMED)

tb_order_progress
├── progress_id (PK)
├── scenario_id (FK)
├── item_code
├── planned_qty / produced_qty
├── status (PLANNED/IN_PROGRESS/COMPLETED)
├── priority (NORMAL/HIGH/URGENT)
├── delay_reason / delay_note
```

## 5. 생산 실적 (생산계획 > 생산 실적)

### 화면 개요
| 항목 | 내용 |
|------|------|
| 경로 | `/plan/production` |
| 목적 | 확정된 생산계획 대비 실적 관리 |
| 레이아웃 | 3단 컬럼 (요약/목록/상세) |

### 핵심 기능

#### A. 전체 현황 대시보드
| 지표 | 설명 |
|------|------|
| 계획 수량 | 전체 계획 합계 |
| 생산 수량 | 실제 생산 합계 |
| 달성률 | 생산/계획 × 100% |
| 지연 제품 | 50% 미만 진행 제품 수 |

#### B. 제품별 진행 목록
- 제품 카드 형태로 표시
- 진행률 바 (색상: 80%↑녹색, 50%↑주황, 50%↓빨강)
- 우선순위/상태 뱃지

#### C. 제품 상세 패널 (우측)
1. **기본 정보**
   - 계획/생산/잔여 수량
   - 실적 수정 입력

2. **공정별 진행**
   - 공정별 진행률 표시
   - 설비코드 표시
   - 상태별 색상 구분

3. **지연 사유 (50% 미만 시)**
   - 사유 선택: 자재부족/설비고장/품질이슈/인력부족/일정변경/기타
   - 상세 메모 입력
   - 저장 기능

### 데이터 구조
```
tb_process_progress
├── id (PK)
├── progress_id (FK → tb_order_progress)
├── op_seq (공정순서)
├── op_name (공정명)
├── machine_code (설비코드)
├── planned_qty / produced_qty
└── status (WAITING/IN_PROGRESS/COMPLETED)
```

### API 엔드포인트
| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | `/scenarios/{id}/progress` | 오더별 진행 조회 |
| PUT | `/progress/{id}` | 생산 수량 업데이트 |
| GET | `/progress/{id}/processes` | 공정별 진행 조회 |
| PUT | `/progress/{id}/delay` | 지연 사유 저장 |
| GET | `/carry-over/{plan_month}` | 이월 대상 조회 |
