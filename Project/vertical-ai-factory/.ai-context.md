## 🔧 개발 시 참고사항

### 1. 환경 변수 (.env)
```bash
GOOGLE_API_KEY=your-google-api-key
OPENAI_API_KEY=sk-proj-xxx...  # ✅ GPT 사용 시
```

### 2. LLM 모델 설정 (src/config.py)
```python
# 현재: Gemini 사용
MODEL_CONFIG = {
    "analyst": "gemini-2.5-flash",
    "writer": "gemini-2.5-flash", 
    "critic": "gemini-2.5-flash",
}

# GPT로 전환하려면 config.py 수정 필요:
# from langchain_openai import ChatOpenAI
# model="gpt-4o-mini"
```

### 3. 실행 방법
```bash
cd /home/roarm_m3/ai-factory-lab/Project/vertical-ai-factory
./venv/bin/python src/main.py
```

### 4. API 할당량 주의
- `gemini-2.5-pro`: Free Tier 사용 불가 (할당량 0)
- `gemini-2.0-flash`: 분당/일일 제한 있음
- `gemini-2.5-flash`: 권장 (Free Tier 사용 가능)
