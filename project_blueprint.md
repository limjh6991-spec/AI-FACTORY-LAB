# Project: Vertical AI Factory (VAF)
## 1. Project Philosophy
- **Role:** An AI-driven Cost Analysis Solution.
- **Core UX:** "Post-Grid". Do not show data grids initially.
- **Flow:** 1. **Insight First:** The dashboard displays "Alert Cards" & "AI Summaries" generated by the backend.
  2. **Data on Demand:** Detailed tables (TanStack Table) are shown ONLY when a user clicks a card.
- **Architecture:** Human Intent -> AI Execution -> Human Approval.

## 2. Tech Stack Requirements
### Frontend (Directory: /web)
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS v4, Shadcn/ui (Lucide React for icons)
- **State Management:** Zustand
- **Data Fetching:** TanStack Query (React Query)
- **Table Lib:** TanStack Table v8 (Headless)

### Backend (Directory: /api)
- **Framework:** Python FastAPI
- **Database:** Supabase (PostgreSQL)
- **AI Integration:** LangChain (for future Agent orchestration)
